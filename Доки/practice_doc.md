# Практическая работа: Разработка веб-сайта Altair

## 1. Идея веб-сайта, цель, задачи, целевая аудитория, миссия

### Идея

Altair — агрегатор AI-инструментов и библиотека промптов. Сайт объединяет информацию о популярных нейросетях и сервисах искусственного интеллекта в одном месте, а также предоставляет платформу для обмена промптами между пользователями.

### Цель

Создать удобный информационный ресурс, позволяющий пользователям находить, изучать и сравнивать AI-инструменты, а также обмениваться готовыми промптами для работы с нейросетями.

### Задачи

1. Разработать каталог AI-инструментов с подробными карточками каждого сервиса (описание, возможности, тарифы, доступность).
2. Реализовать библиотеку промптов с возможностью публикации, поиска, лайков и комментирования.
3. Внедрить систему регистрации и авторизации пользователей.
4. Обеспечить фильтрацию контента по категориям и AI-моделям.
5. Реализовать административные возможности для модерации контента.
6. Опубликовать сайт на хостинге с постоянным доступом.

### Целевая аудитория

- Студенты и учащиеся, изучающие возможности искусственного интеллекта.
- Специалисты и фрилансеры, использующие AI-инструменты в работе.
- Разработчики, ищущие информацию о API и возможностях нейросетей.
- Широкая аудитория, интересующаяся технологиями и нейросетями.

### Миссия

Сделать мир AI-инструментов доступным и понятным для каждого — собрать актуальную информацию о нейросетях, помочь пользователям найти подходящий инструмент для своих задач и создать сообщество, где люди делятся опытом и эффективными промптами.

### Системы управления веб-сайтом (CMS)

Проект Altair разработан без использования традиционных систем управления контентом (CMS), таких как WordPress или Joomla. Сайт построен на современном стеке технологий:

- **React 19** — библиотека для построения пользовательского интерфейса;
- **Vite** — инструмент сборки и разработки;
- **Supabase** — облачная база данных PostgreSQL с встроенной системой авторизации, выполняющая роль backend-платформы;
- **React Router** — маршрутизация между страницами.

Управление контентом осуществляется напрямую через интерфейс сайта авторизованными пользователями и администраторами, а также через панель управления Supabase.

## 2. Домен, хостинг и локальная установка

### Хостинг

Сайт размещён на платформе **Netlify** — современном облачном хостинге для статических сайтов и JAMstack-приложений. Netlify обеспечивает:

- Автоматический деплой при каждом push в репозиторий GitHub;
- Глобальную CDN-сеть для быстрой загрузки;
- Поддержку переменных окружения для хранения ключей API;
- SSL-сертификат (HTTPS) без дополнительной настройки.

**Адрес хостинга:** [https://www.netlify.com](https://www.netlify.com)

### Доменное имя

Сайт доступен по адресу, предоставленному платформой Netlify:

**https://altair-ai.netlify.app**

Домен третьего уровня в зоне `.netlify.app` предоставляется бесплатно при регистрации на платформе. Регистрация собственного домена (например, `altair-ai.ru`) не производилась в рамках данного проекта.

### Локальная установка

Для локального запуска проекта необходимо:

1. Установить Node.js версии 18 и выше.
2. Клонировать репозиторий: `git clone https://github.com/retro7565/altair.git`
3. Установить зависимости: `npm install`
4. Создать файл `.env` с переменными `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. Запустить сервер разработки: `npm run dev`

Сайт будет доступен по адресу `http://localhost:5173`.

## 3. Шаблоны для веб-сайта

### Позиция по шаблонам CMS

Веб-сайт Altair является полностью самостоятельной разработкой и не использует готовые шаблоны ни для каких CMS-систем. Весь дизайн и пользовательский интерфейс разработан с нуля в рамках данного проекта.

### Используемые дизайн-решения

Визуальный стиль сайта основан на следующих принципах:

- Тёмная цветовая схема (фоновый цвет `#0d0d14`, акцентный цвет `#6366f1`);
- Минималистичный интерфейс в стиле современных SaaS-продуктов;
- Использование встроенных стилей (inline styles) в компонентах React для гибкости и независимости от внешних CSS-фреймворков;
- Адаптивная сетка на основе CSS Grid и Flexbox.

### Сравнение с CMS-шаблонами

| Параметр | Шаблон CMS | Altair (собственная разработка) |
|---|---|---|
| Гибкость | Ограничена шаблоном | Полная свобода |
| Скорость старта | Быстрая | Требует разработки |
| Уникальность | Низкая | Высокая |
| Зависимость от сторонних плагинов | Высокая | Минимальная |
| Поддержка | Сообщество CMS | Собственная |
